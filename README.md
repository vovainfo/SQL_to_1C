Внешняя обработка для замены объектов БД в SQL запросе на объекты 1С.

1. Запустите свою конфигурацию в режиме управляемого приложения.
2. Откройте обработку. Структура БД автоматически загрузится. Можете её исследовать на закладках "Структура БД" и "Поля БД".
3. На закладке "Запрос" вставьте SQL запрос в поле "Запрос SQL".
4. Нажмите кнопку "Парсинг SQL запроса".
5. Нажмите кнопку "Сформировать 1С запрос".

Дополнительный функционал: нажатием на кнопку "Сохранить структуру БД в файл" можно выгрузить файл со структурой БД, который потом на другой конфигурации можно будет загрузить на другой конфигурации кнопкой "Загрузить структуру БД из файла". Естественно, данные загружаются только для анализа в обработке, в конфигурации ничего не меняется.
